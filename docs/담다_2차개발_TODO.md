## 2. 사장님 페이지

**구조 개편** *(다른 항목들의 토대 — 먼저)*
- [ ] **사업자 → 사업장 → 상품** 단계 구조로 정리
- [ ] 사업장 옵션을 **야놀자 방식**(사업장 안에서 상품을 선택해 들어가는 방식)으로 변경 — 📎첨부-1
- [ ] **마감 설정을 사업장 단위 → 상품 단위로** (상품별 날짜 마감 = 휴무일 지정과 비슷)
  - 사업장 단위 기능은 유지: 노출/비노출, 휴무일 지정
- [ ] 사장님이 **직접 상품 등록·수정** 가능 (등록 즉시 사이트 반영)
- [ ] **사업장 정보 수정은 요청 → 관리자 D+1(1영업일) 승인**
- [ ] 예약 취소는 **관리자만** 처리 (기존 유지)

**모바일 / 문구**
- [ ] 모바일에서 **대시보드 / 예약상세 글자 배치** 정리
- [ ] 모바일에서 **홈(대시보드)으로 돌아가는 버튼** 추가
- [ ] 예약상세 문구 **"예약일" → "이용일"**

**기능 추가**
- [ ] **알림톡 수신 번호 직접 설정·수정** — 본인 + 추가 1명 (추가 시 관리자 승인)
- [ ] 상품 등록 시 **편의시설 / 서비스 항목 설정·노출** — 📎첨부-4
- [ ] **자동 로그아웃** — 일정 시간 미사용 시 로그아웃 (하루 유지). *플랫폼·사장님 공통*

## 3. 어드민 (관리자)

**메뉴 개편**
- [ ] **"업체관리" → "상품관리"** 이름 변경
- [ ] 상품관리를 **사업주관리 하위로** 이동 (사업주 상세 페이지에 '상품관리' 탭)
- [ ] 사업주 선택 → 업체 목록 → 업체 클릭 → 업체 수정 페이지 흐름

**판매방식 다양화** *(핵심 / 대형)*
- [ ] 상품 **판매방식 3종** 선택
  - 방식 1 — **당일 1건만** 예약 (최소/최대 인원 무관)
  - 방식 2 — **시간대별** 예약 (오전/오후 등, 복수 선택 불가)
  - 방식 3 — **개수별** 예약 (예약 시 잔여 수량 차감, 상품 페이지에 잔여 수량 노출)
- [ ] 방식 2·3은 **요일별 설정**도 가능
- [ ] 시간대 예약 시 **한 시간대가 차면 다음 예약을 막을지 설정** (기본: 막힘) — 동화열차처럼 하루 여러 회차 대응
- [ ] **요일별 예약 가능 인원 수** 설정

**버그**
- [ ] 사업자 최초 등록 후 수정 시 **세금계산서 이메일이 공란**이 되는 버그 수정
